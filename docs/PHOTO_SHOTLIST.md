# goldsky.ca 实拍照片清单

这些位置**只能用真实照片**，不能用 AI 生成图：它们是真实门店、真实终端、真实使用场景的证据。
氛围插图另有规范，见 `IMAGE_STYLE.md`。

在网站上，这些位置现在显示为橙色虚线框，框里写着拍摄要求。

## 怎么替换

1. 照片导出成 WebP，放进 `public/photos/`，文件名和下表一致。
2. 打开 `lib/photos.ts`，找到对应条目：写好 `alt`（英文，一句话说明照片内容），把 `ready` 改成 `true`。
3. 页面会自动显示照片，占位框消失。

## 通用要求

| 项目 | 要求 |
|---|---|
| 格式 | WebP，单张 300KB 以内（先导出 JPG 高质量原图留底） |
| 尺寸 | 不小于下表的最小尺寸，宁大勿小 |
| 光线 | 自然光优先，清晨或傍晚的暖光最好；避免正午顶光和闪光灯 |
| 调色 | 暖白平衡、黑位略提、细颗粒、饱和度略低；橙色是画面里唯一的强色（同 `IMAGE_STYLE.md`） |
| 构图 | 留白多，主体不要顶边；横图预留上方天空，竖图预留上下余量供裁切 |
| 人物 | 可辨认的人脸必须有书面肖像授权；没有授权就只拍手、背影或侧身虚化 |
| 车牌 | 不能有可辨认的车牌 |
| 品牌 | 画面里出现的第三方品牌（洗车药剂、车标等）尽量避开或虚化 |
| 门店授权 | 拍门店前取得店主同意，并确认可以在官网公开使用 |
| 真实性 | 只做调色和裁切，不做合成、不加设备、不改屏幕内容 |
