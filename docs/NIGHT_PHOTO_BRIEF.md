# 深色版写实照片：需求与提示词

深色版仿 starlink.com：纯黑页面，大幅照片铺满整屏，白色粗体 DIN 风格字体，白底黑字按钮。
浅色版继续用版画插画，深色版改用写实照片，两套图互不混用。

**「深色」指的是页面配色，不是照片里的时间。** 照片和插画讲同一个故事：小镇的一天。

| 时间 | 页面位置 | 照片 |
|---|---|---|
| 06:00 日出 | 首屏 | hero |
| 08:00 开门 | 场景选择器（自动轮播时也走一遍一天） | counter 7:30 → dinein 12:00 → wash 15:00 → vend 17:30 → sites 21:00 |
| 18:00 黄昏 | 标语区 | golden |
| 23:00 深夜 | Aegis 区 | aegis |
| 次日 06:00 | 「三步开始」，接着就是联系表单「Tomorrow, first light」 | summit |
| 黄昏 | 404 页面 | not-found |

代码位置：`lib/nightPhotos.ts`（照片清单），`components/NightPhoto.tsx`（显示组件）。
**照片文件放好就会自动显示**，不需要改代码。文件还没到位时，该位置显示深色渐变，并标出缺的文件名和尺寸。

## 规则

- **格式与目录**：JPG，sRGB，放进 `public/images/night/`。原图带黑边和水印也可以，我来裁。
- **用途**：只用作氛围照，画面是泛指的场景和手部特写，**不能冒充 GoldSky 的客户现场**。真实门店的照片仍然走 `lib/photos.ts`，必须是实拍。
- **画面里不要出现任何可读文字**：没有招牌、品牌、车牌，屏幕上也没有字。
- **Starlink 质感**：每张都按照片所处的时间用真实的自然光。整体略微欠曝，像电影画面，低饱和，暗部深。
  - 画面底部和左侧过渡到很暗，用来压标题文字，也方便和纯黑页面衔接。
  - 不要 HDR，不要霓虹紫或青色，不要镜头光晕。
- **一致性**：所有照片里是同一座小镇、同一座雪山。加拿大，冬末，地上有残雪。
- **终端**：只画刷卡读卡器或带小屏幕的终端，**不要油枪、不要软管**，不能像加油站或充电桩。

## 生成设置：底部留黑边给水印

生成时故意选比最终尺寸**更高**的比例，底部多出来的纯黑横条留给 AI 水印，我裁掉后再裁成网页尺寸。
主体都放在画面上方 85% 以内；右下角保持暗，因为豆包的水印在右下角。
每张可以多生成几次，挑底部最干净、画面没有文字的那张。

| 文件名 | 生成时选的比例 | 最终尺寸 |
|---|---|---|
| hero.jpg、golden.jpg、aegis.jpg | 16:10（或 3:2） | 2560×1440 |
| counter、dinein、wash、vend、sites、summit | 3:4 | 1600×2000 |
| not-found.jpg | 3:2 | 1600×1000 |

**中文**：
> 写实商业摄影，像 Starlink 官网的大片：电影感，真实自然光，略微欠曝，暗部深沉，低饱和，干净极简，大量留白，细腻胶片颗粒，全画幅相机，浅景深。画面中不要任何文字、招牌、标志、品牌、车牌或水印。画面最底部约 10% 高度是一条纯黑色（#000000）横条，横条里什么都没有，上方画面自然过渡成黑色。

No text, no signage, no logos, no brand names, no license plates, no watermark.
